# “医生，我的便便从阴道出来了？！”急产妈妈遭遇尴尬的……

> 更新时间：2026-09-16 (UTC+8)

“医生，我的便便从阴道里出来了……”

女性产后漏尿

常被人们称为尴尬的社交病

然而26岁的小蔡（化名）却在生产后

遭遇到了更为尴尬和难受的疾病

——**直肠阴道瘘**

**产**

**01**

**后**

**产后1天发现大便从阴道漏出来了，**

**两次缝合手术未见效果**

26岁的小蔡初为人母，宝宝还未满月，本该尽情享受与宝宝亲密接触的她，却被**“粪瘘”**问题困扰不已，只能多次往返医院。

去年8月，怀孕足月的小蔡在外院顺产分娩3400g的宝宝，总产程3小时左右。由于小蔡2年前曾有过一次大孕周引产史，产道松弛，导致此次分娩产程较短，急产导致了小蔡出现**深度会阴裂伤**。

”

**产后1天**，小蔡便发现本该从肛门排出的粪便不时从阴道漏了出来……

**产后1周**，小蔡伤口未见愈合，粪便从阴道流出的情况仍然没有改善，小蔡便返回当地医院行了会阴裂伤缝合术，但由于伤口过深，缝合后小蔡的症状并未好转。

**产后第二周**，小蔡又经历了 1周阴道噗呲噗呲放屁、粪液不自主流出……小蔡又进行了第二次会阴裂伤修补术，但由于当时小蔡的伤口正处于组织水肿期，且经过了粪便的污染，此次的缝合也没有得到很好的愈合。

”

**产**

**02**

**后**

**尴尬的阴道直肠瘘，**

**沉重的心理负担**

“医生，我这个月子基本没坐，还多经历了两次手术，简直像是生了三次孩子……每天都担心大便漏出来，好痛苦，能不能帮我治好这个病……”

痛苦不堪的小蔡辗转来到广州医科大学附属第三医院妇科盆底诊治中心就诊，向刘娟主任医师讲述了自己的痛苦和尴尬，并希望能够彻底解决这个问题。

刘娟主任详细询问了小蔡的病史，并在体检检查中发现患者会阴后联合近肛门口约1cm处可见一直径0.5cm瘘口，与肛管相通，并进行盆底超声提示阴道后壁下段近阴道口处可见一条状低回声区与直肠相通，宽约1.3mm，考虑阴道直肠瘘可能。

**直肠阴道瘘**

“直肠阴道瘘是直肠和阴道之间形成的先天性或后天性通道，临床上比较少见，其发病原因很多，如自然分娩时会阴裂伤、侧切缝合不当、手术损伤、吻合器术后并发症、炎性肠病、感染、癌性瘘等。”

刘娟主任医师解释说，“其主要的临床表现是阴道排气、排便，严重时大便不能够自己控制，**一般情况下无法自愈，大部分的患者需要手术治疗。**如果处理不当，会导致反复感染、疼痛等，还会使患者承受巨大的精神压力，严重影响患者生活质量。”

**产**

**03**

**后**

**科学管理，选择手术时机，**

**1小时手术帮助患者恢复正常生活**

由于小蔡多次手术史，保守治疗难奏效，需再次行手术修补。刘娟主任团队经过详细检查及考证，考虑蔡某产后1个月，且多次会阴缝合操作，会阴仍处于组织水肿期，并非手术的最佳时机，**暂时先予抗感染，指导阴道护理，大便管理等，定期门诊复诊评估外阴伤口情况，择期手术修补。**

3个月后，小蔡再次来到门诊，经过科学的管理，此时她的外阴伤口水肿已经消退，瘘管形成，瘢痕软化，手术的时机到了。

经过了几天的肠道准备，今年1月11日，刘娟主任医师及林琼燕副主任医师为小蔡进行了手术，经过仔细分离瘘管壁的瘢痕组织，**不到1个小时的手术，就将患者直肠与阴道之间的异常通道完全缝合起来，并重新修补了陈旧的会阴裂伤**，术后更是细心的护理伤口及完善的术后营养支持治疗。

“谢谢医生，我终于可以正常大便了！”出院后1个月，小蔡又来到门诊复诊，一改往日愁容，她开心地向医生表示。

正常排便，这对大多数人不过是非常平常的小事，但对小蔡来说却是失而复得的可贵体验。至此，小蔡终于摆脱了粪瘘的尴尬，恢复了正常的生活。

**产**

**04**

**后**

**专家提醒：孕妇要警惕急产，**

**出现会阴裂伤要注意护理**

**急产指从规律宫缩到胎盘娩出总时长小于3个小时**，多见于经产妇、软产道松弛、宫缩强、骨盆宽大、胎儿体重较轻或早产者。

**急产对于母婴都可能危害较大**：

- 
急产的孕妇由于产道来不及扩张容易发生严重裂伤、产后出血和产褥感染等。

- 
急产的宝宝则由于子宫收缩过强、间歇过短，胎盘血液循环常常在产程中被阻断，易发生胎儿窘迫、新生儿窒息甚至死亡，同时胎儿娩出过快，颅内压力突然改变会引起胎儿的颅内血管破裂，引起颅内出血等。

刘娟主任医师、林琼燕副主任医师提醒，经产妇、有过早产史、引产史的孕妈要警惕急产的发生，没有高危因素的孕妈到孕晚期也要时刻注意自己的产兆，**如出现5分钟左右1次，1次持续30s以上的规律宫缩、见红、破水或者是有强烈的便意等情况要及时到医院就诊。**

如果产后出现了会阴裂伤，要加强会阴部的护理，避免更严重的并发症：

第一、一定要注意会阴清洁，勤用温水清洗会阴，特别是大小便后，避免伤口污染。

第二、合理饮食，加强营养，促进伤口愈合。

第三、会阴伤口比较深时，一定要遵嘱循序渐进增加饮食，预防便秘。

第四、健侧卧位，如伤口在左侧，则采取右侧卧位，避免恶露污染。

第五、一旦发现伤口有红肿，流血流脓，或者有缝线不吸收等，及时到医院就诊。

刘娟主任医师、林琼燕副主任医师提醒，直肠阴道瘘因病变部位较为隐私，一些轻症患者可能会不好意思到医院就诊，但**如果延误就诊导致病情加重后，其治疗会更为复杂**，应遵医嘱选择合适的手术时机，方能更好地得到伤口愈合。因此**建议患者出现不自主地阴道内排气、阴道内流粪水或排出粪便时，应及时到医院就诊。**

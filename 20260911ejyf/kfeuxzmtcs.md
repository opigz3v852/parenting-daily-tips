# 在广州想生孩子哪家医院能做xy精子分离术，15万多已足够！

> 更新时间：2026-09-11 (UTC+8)

广州目前并没有私立生殖中心有开展xy精子分离术，xy精子分离术是利用Y精子比重较轻、跑得较快的原理，将X和Y精子分开，再用人工授精或是试管婴儿的方法怀孕。但目前国内并没有这项技术，想生个孩子，在国内可以通过三代试管婴儿技术来实现，但是对于三代试管婴儿选试管国内政策有严格要求。

目前广州市内能开展生殖怀孕的医院都是公立的，而且国内政策也不允许无医学指征的情况下做试管婴儿进行试管筛选，但是有传男不传女或传女不传男的疾病的家庭是可以通过第三代试管婴儿进行试管筛选达到生孩子的目的的，根据广州三代试管医院排名来看，成功率比较高的医院有广州市妇女儿童医疗中心、广东省妇幼保健院、广州医科大学附属第三医院等：

- 1.广州医科大学附属第三医院（广医三院），位于广州市荔湾区多宝路63号；
- 2.中山大学附属第六医院（中山六院），位于广州市天河区瘦狗岭路17号；
- 3.广州市妇女儿童医疗中心（广州妇幼保健院），位于广州市天河区金穗路9号；
- 4.中山大学附属第一医院（中山一院），位于广州市越秀区中山二路1号；
- 5.广东省妇幼保健院（广东省妇幼），位于广州市番禺区兴南大道521、523号；
- 6.中山大学孙逸仙纪念医院（孙逸仙医院），位于广州市越秀区沿江西路107号。

不仅广州没有私立生殖医院可以做xy精子分离术，国内任何公立医院也没有开展，想生个孩子要做xy精子分离术可以去国外做，目前美国、柬埔寨、泰国等都有这项技术，怀孕费用2到4万元不等。
